# ADR-003: UI System

## Status

Proposed

## Decision

Use a German-language, light, mobile-first UI with dark blue, white, and red
tokens. Use neutral original assets until brand permissions are clarified.

## Rationale

This matches Austrian handball context while preserving a clear independent
pilot identity. Mobile priority serves common venue and schedule lookup flows.

## Deferred Decisions

- Dark mode.
- English translation.
- Official OEHB, OOHV, or HLA assets.
