# Spec Delta

## Purpose

Lets players and parents put a team's fixtures into their own calendar.

## ADDED Requirements

### Requirement: Team calendar file
Each team page SHALL offer an iCalendar (.ics) download containing all of the team's matches of the season with date, time, opponent, venue address and match number.

#### Scenario: Traun calendar
- **WHEN** the user downloads the Traun HLA calendar
- **THEN** the file contains 14 events and the 15.11.2026 event is "SK Konstant Traun / Edelweiss – SMC Innsbruck Handball Tirol" at Sportzentrum Traun
